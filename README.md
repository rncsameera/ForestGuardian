\# 🌲 ForestGuardian



\*\*An AI-Powered Forest Ecosystem Exploration and Conservation Project\*\*



ForestGuardian is a Unity-based project that combines an interactive forest environment with Artificial Intelligence concepts. It explores how intelligent systems can support forest conservation, wildlife awareness, and ecosystem management through an engaging exploration experience.



\## 🎯 Project Objectives



\- Create an interactive 3D forest environment for exploration.

\- Demonstrate AI search, reasoning, and decision-making concepts.

\- Represent wildlife and ecosystem-related interactions.

\- Explore how computational intelligence can support conservation activities.



\## ✨ Features



\- \*\*3D Forest Environment:\*\* Procedurally generated terrain and forest surroundings.

\- \*\*Player Exploration:\*\* First-person and camera-mode controller components.

\- \*\*Wildlife Systems:\*\* Animal movement, spawning, and procedural animal visuals.

\- \*\*Conservation Interactions:\*\* Components for resource collection, shelter interactions, pond restoration, and environmental inspection.

\- \*\*Gameplay Interface:\*\* HUD, minimap, world map, and game-flow components.

\- \*\*Ecosystem Systems:\*\* Components for ecosystem state, weather, world time, and conservation quests.

\- \*\*Python AI Integration:\*\* Python scripts and a Unity bridge for exploring AI algorithms.



\*Feature availability and behaviour may vary depending on the current Unity scene configuration.\*



\## 🧠 Artificial Intelligence Concepts



The project includes Python implementations or modules related to:



| Concept | Purpose |

|---|---|

| Breadth-First Search (BFS) | Explores states level by level |

| Depth-First Search (DFS) | Explores paths deeply before backtracking |

| A\* Search | Finds paths using cost and heuristic estimates |

| Constraint Satisfaction Problems (CSP) | Models problems using variables and constraints |

| Bayesian Reasoning | Represents reasoning under uncertainty |

| Logic | Demonstrates logic-based reasoning |

| Planning | Represents action sequences toward goals |



These concepts connect classroom AI topics with a practical interactive project.

\- `Assets/Scripts/` contains the Unity C# scripts.

\- `Assets/Scenes/` contains the Unity scenes.

\- `Assets/StreamingAssets/PythonAI/` contains Python modules packaged for the Unity project.

\- `PythonAI/` contains standalone Python AI modules and sample input/output files.

\- `ai/` contains additional AI-related Python code.

\- `Packages/` and `ProjectSettings/` contain Unity configuration.



\## 🚀 Getting Started



1\. Install a compatible version of Unity.

2\. Clone or download this repository.

3\. Open Unity Hub and select \*\*Add project from disk\*\*.

4\. Select the cloned `ForestGuardian` folder.

5\. Allow Unity to resolve packages and import assets.

6\. Open `Assets/Scenes/ForestGuardian\_Main.unity`.

7\. Press \*\*Play\*\* to test the scene.



\*\*Note:\*\* Python-dependent features may require a compatible Python installation and appropriate configuration. Check the project scripts and setup before running those features.

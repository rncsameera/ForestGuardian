FORESTGUARDIAN - GTA STYLE PASS 1

This is an overlay patch for the ForestGuardian Unity project.
Copy the contents of this folder over the matching Assets/Scripts paths in your project.

Changes:
- Camera-relative third-person movement with smoother turning.
- Contextual interaction wording instead of generic "Interact" prompts.
- Animals are now contextual Interactable objects: sick/thirsty/hungry animals can receive appropriate care when approached.
- Horizontal GTA-style compass strip in the top HUD.
- Mission language shifted toward exploration/investigation/consequences rather than repetitive cleanup wording.
- No Python/Bayesian terminology was added to player-facing UI.

Note: This environment does not have the Unity Editor or dotnet CLI available, so compilation/Play Mode could not be run here. The modified C# files were checked for balanced braces.
